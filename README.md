## 怎么读这两册

选型顺序建议是 **Agent → 平台 → 模型**：先确定任务由哪个 Agent 承接（本地 Agent 还是外部平台），再决定在哪个平台掏钱、买哪一档，最后才是在该平台里挑具体型号。

- **不能直接换算的两件事**：模型层的倍率是 WorkBuddy 内部积分相对值，和平台层的人民币单价不在同一个坐标系；平台层的 ¥/秒 是「一条指令的实付成本」，和模型层的每百万 token 价格也不是一回事。跨层比较前先回到「这一条活要花多少钱」这个共同问题。
- **平台层可比的前提是口径统一**：各家积分名目不同（积分 / 创作币 / 星 / 盒饭 / 算力），只有统一折算到同一条指令——`Seedance 2.5 · 9:16 · 1080P · 1 · 30s · 图生视频`——才谈得上比价。

## 核心结论

- **模型层**：**一致性靠上下文长度**（hy4-preview-f / 1M 档）、**文笔靠 Kimi**、**代码靠 MiniMax · GLM**、**跑量靠免费档**
- **模型层**：倍率是积分相对值，模型之间可直接比较，但不能与外部 API 的人民币单价直接换算
- **模型层**：不是所有任务都该留在 WorkBuddy 里——整仓重构用 Claude Code、可控改图用 Seedream、自建服务用 Qwen 开源权重
- **平台层（2026-10 改版）**：统一口径切到 **Seedance 2.5 · 1080P · 30s**，参评 11 家（新增 Higgsfield）。秒价 ¥1.61–¥4.86，30s 单条 ¥48.4–¥145.7，年产能 17.6–133.7 条。最便宜 LibTV（¥1.61/秒），产能最高 NeoWOW（133.7 条/年），最贵万兴剧厂（¥4.86/秒）
- **平台层**：**官方按量反而最贵** —— 火山官方套餐 561 积分/秒 = ¥5.61/秒，比全部 10 家会员平台都贵。会员制的本质是拿「锁定一年」换 3–5 折
- **平台层**：**Higgsfield 值不值看用途** —— Seedance 2.5 单价 ¥4.51/秒（倒数第二贵，比国内会员贵 2.6–2.8 倍），但它把「下单前查价」做成 CLI 命令 `generate cost`，是唯一能把成本写进脚本的聚合平台
- **平台层**：11 家里 **7 家拿到实价**（均 30s · 1080P）—— LibTV **3,300 积分**（→¥1.74/秒）、Shotlab **1,650 创作币**（→¥1.83/秒）、小云雀 **1,920 积分**（→¥2.23/秒）、即梦 **1,920 积分**（→¥2.25/秒）、NeoWOW **18,450 星**（→¥3.27/秒）、OiiOii **55 盒饭/秒**（→¥3.34/秒）、Higgsfield **480 cr**（→¥4.51/秒）；剩 4 家按 1.5 倍推算
- **平台层 · 前四已锁定**：LibTV ¥1.74 ＜ Shotlab ¥1.83 ＜ 小云雀 ¥2.23 ＜ 即梦 ¥2.25，全部实价。LibTV 比第二名便宜 5%、比第三名便宜 22%。剩下 4 家的估值即使全错 ±45%，也翻不动这四位
- **平台层 · 实测校准**：1.5 倍这座桥时准时不准 —— 实测比值 **1.08×（即梦）· 1.53×（Shotlab，误差 1.9%）· 1.57×（OiiOii）· 1.62×（LibTV）· 1.64×（NeoWOW）· 1.94×（小云雀）**。Shotlab 一次就中，小云雀被低估 23%。**桥本身没错，错在假设它对所有平台成立 —— 剩余 4 家必须逐个实测**
- **平台层 · banner 价是诱饵**：LibTV 首页「2.5 · 720P · 0.19 元/秒」vs 实测 1080P **¥1.74/秒**，差 **9.2 倍**；小云雀「低至 ¥0.177/秒」vs 实测 **¥2.23/秒**，差 **12.6 倍**。分辨率只解释 2.5–3.2 倍，其余 4 倍是年卡+促销+draft 叠出来的组合价。**看到「低至」「起」直接当不存在**
- **平台层 · 字节系同价**：小云雀与即梦在 2.5 · 1080P · 30s 上都是 **1,920 积分**，消耗完全一致 —— 同一套计费系统，两家只差 ¥/积分（0.0349 vs 0.0352）。选谁只看会员折扣，不看模型
- **平台层 · 剩余 4 家**：Updream（¥2.93）· TapNow（¥3.11，双重外推）· Seko（¥3.34）· 万兴剧厂（¥4.86）。全部排在实价第一梯队之后，估值偏差不影响采购结论
- **平台层**：三家官方「起 / 低至」价只有满血实测的约 1/3，会员档位比按次买便宜得多——先比年会员折算单价，再谈要不要砍到更低的档
