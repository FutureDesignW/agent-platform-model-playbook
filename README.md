## 核心结论

- **一致性靠上下文长度**（hy4-preview-f / 1M 档）、**文笔靠 Kimi**、**代码靠 MiniMax · GLM**、**跑量靠免费档**
- 倍率是积分相对值，模型之间可直接比较，但不能与外部 API 的人民币单价直接换算
- 不是所有任务都该留在 WorkBuddy 里：整仓重构用 Claude Code、可控改图用 Seedream、自建服务用 Qwen 开源权重
